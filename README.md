# ChargerMap by FLUI ⚡

O dashboard do ChargerMap by FLUI é a plataforma web administrativa desenvolvida para gerenciamento dos pontos de recarga da aplicação.

O sistema foi criado como parte do Charge Platform Challenge, proposto pela FIAP, com foco em mobilidade elétrica, gestão inteligente e experiência digital.

---

# 💻 Funcionalidades

- Painel administrativo;
- Visualização de postos cadastrados;
- Cadastro de novos pontos de recarga;
- Edição de registros;
- Tela de avaliações;
- Layout responsivo;
- Navegação entre páginas.

---

# 🎨 Identidade Visual

## Paleta de cores
- `#B947FA`
- `#555799`

A identidade visual foi pensada para fugir do padrão tradicional de mobilidade elétrica baseado em verde e azul escuro, trazendo tons de roxo modernos que mantêm a conexão com tecnologia, inovação e sustentabilidade.

## Tipografia
- **Hanken Grotesk** → títulos e destaques
- **Poppins** → textos gerais da interface
